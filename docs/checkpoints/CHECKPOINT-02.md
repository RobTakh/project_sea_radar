# Checkpoint 02 — три демонстрационных судна, движение и браузерные тесты

## Запуск

`npm install`
`npm run dev`
`npm run test:e2e`

## Что сделано

- При открытии приложения отображаются ровно три демонстрационных судна: `demo-1`, `demo-2`, `demo-3`.
- Для каждого судна в конфигурации заданы литеральный маршрут из 8–12 точек и литеральная скорость; точки маршрутов выбраны в водной акватории пролива.
- Каждые 2000 мс суда переходят к следующим точкам своих маршрутов одним общим таймером.
- Курс судна вычисляется как начальный азимут большого круга между точками маршрута.
- В момент перехода обновляется время сообщения; на последней точке скорость становится `0`, курс сохраняется, дальнейшие переходы не выполняются.
- Карточка выбранного судна получает актуальные координаты, скорость, курс и время из того же состояния, что и карта.
- При уходе со страницы общий таймер очищается.
- Настроен Playwright Test с единственным проектом `chromium` и автоматическим запуском `npm run dev` перед тестами.
- Добавлены три браузерных теста: количество судов, карточка выбранного судна и сохранение карточки после повторного клика.
- Запросы к тайлам OpenStreetMap в браузерных тестах блокируются.

## Проверки
