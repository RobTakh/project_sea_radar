# Checkpoint 01 — карта и демонстрационное судно

**Архив:** `sea-radar-checkpoint-01-<sha>.zip`, где sha — коммит, в который входит эта запись
**Дата:** 2026-09-10  **Задачи:** B-01…B-04

## Запуск

`npm install`
`npm run dev`

## Что сделано

- При открытии приложения отображается страница Sea Radar с заголовком «Sea Radar — пролив Дувр».
- В приложении предусмотрена карта Дуврского пролива с центром 51.00° N, 1.45° E и масштабом 10.
- Для карты настроен слой OpenStreetMap с атрибуцией «© OpenStreetMap contributors».
- На карте предусмотрено одно демонстрационное судно `demo-1` со значком, ориентированным по курсу.
- В боковой панели указана подпись «Демонстрационные данные».
- Выбор судна открывает карточку с идентификатором, названием, координатами, скоростью, курсом, временем и источником.
- В карточке имя судна выводится как текст.
