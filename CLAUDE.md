# Sea Radar

## Стек

Next.js с App Router, React, TypeScript в режиме `strict`.

## Запуск

```bash
npm install
npm run dev
```

Приложение открывается на `http://localhost:3000`.

## Границы текущей недели

Минимальный каркас приложения без лишних зависимостей, примеров и демонстрационных страниц. ESLint и Tailwind не подключаются. Папки под будущие задачи не создаются.

Секреты не читать и не выводить.
